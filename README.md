# LIMASU REGALIA

Cinematic private-membership experience built with Next.js, Tailwind CSS, GSAP ScrollTrigger, Motion, and React Three Fiber.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js + TypeScript
- Tailwind CSS
- shadcn-style UI primitives
- GSAP + ScrollTrigger
- Motion for React
- Three.js + React Three Fiber + Drei
- Lucide-ready icon surface

## Content

Copy, tiers, services, network pillars, and escrow stages live in `src/lib/site-config.ts`.
